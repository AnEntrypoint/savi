# Portals

```js
// spawn: { id: "gate-east", tags: ["portal"], behavior: "scripts/gate.js", state: { link: "+cellar#gate-west" }, rotation: 90, primitive: { kind: "arch", width: 2.6, height: 3.4, depth: 0.3 },
//   physics: { body: "static", trigger: true }, material: { kind: "scripted", script: "engine/portal-ember", view: { link: "+cellar#gate-west", spill: 2, sound: 1 } },
//   children: [ { id: "arch", primitive: { kind: "archway", width: 3.4, height: 3.8, depth: 0.6, thickness: 0.4 }, physics: "static", material: { color: "#6b6258", roughness: 0.95 } } ] }
// spawn, in the cellar, the twin: the same with id "gate-west", rotation: 270, both links "+main#gate-east"
export function onTriggerEnter(ctx, other) {
  ctx.cross(other, ctx.self.state.link);
}
export function onCross(ctx, other) {
  ctx.emit("playSound", { clip: "cdn/gate-chime.mp3", position: ctx.self.worldFeetPosition });
}
export function onRefuse(ctx, other, verdict) {
  ctx.emit("uiEvent", { name: "refused", payload: { message: verdict.message } }); // the script says what happened; ui.js draws it
}
```

- The glass is the opening's shape: an `arch` of the opening's `width` and `height` fills an `archway` of that profile edge to edge (frame `width + 2 × thickness` by `height + thickness`); any other doorway takes a scripted-geometry glass cut to it (→geometry). `material.view` paints any shape.
- A door to another creator's world needs no pasted link: `spawn browse --creator <handle>` (or `spawn browse "<words>"`) finds it, published or not; its address is the link, `link: "@ress/cathedral +main"` (the card at `--address` names its places). `gate.destination.onlineCount` counts who plays there (null until known).
- `#exit` is the gate you step out of, written on BOTH gates. Gates come in pairs, sized alike, each facing the side you approach from, the way you walk out (a gate faces −Z at `rotation: 0`). A link naming only the place (`+cellar`) steps out of the far gate whose link names yours back; with no such gate you land at the place's `arrival`, else its spawn: a cut, not a doorway. The gate's own script crosses the body (`onTriggerEnter`): the crossing waits for the glass and keeps your heading: you step out as you stepped in; a body crossing itself lands at once at the exit, facing out.
- A door's link is where it leads, for everyone: its glass, warm-up and crossing read it; it wears that glass, tinted by its `color`, until `material.view: null` leaves a plain face that still crosses. A linkless door sending each walker somewhere of their own (garden, den) holds them at the glass while theirs loads. Give each player their own instead: their script spawns it with `audience: "local"` and `link: player.den`.
- The glass: `material.view: { link, spill, sound, oneWay }`: the far place seen through the face, its light on your ground. `oneWay: true` is a one-faced door: veiled behind, closed to travelers there. Presets `script: "engine/portal-<name>"`: glass, water, ember, ink, veil, mirror-break, pixel, stained-glass, static, starfield, aurora, honeycomb, oil-slick (the rift is the return door's torn disc, not a slab): a preset styles the frame; the far world inside stays clear and still at every distance (`params: { warp: 1 }` restores the old whole-glass look); a door with no preset samples the far world with `ctx.view(offset)` (its ctx: spawn api builtin/three).
- `material.view: { camera }` is a camera; `spawn api ViewCamera` has the rest. `camera: "mirror"` is a mirror (`hideLocalPlayer` hides your body from the screen's eye alone): a plane in `material: { color: "#0b0e12", view: { camera: "mirror" } }`; `camera: { eye, aim, fov }` is a placed camera: a security monitor, or a map (eye high, aiming down, `projection: "orthographic"`, `orthoSize`). `layers` picks what a camera draws (default `["default"]`): icons on `["icons"]` show on a map with `layers: ["default", "icons"]`, roofs on `["roofs"]` where the screen's `camera.layers` names them, a ghost on `["ghost"]` in `{ mirror: true, layers: ["default", "ghost"] }`. `camera: { parent: id, eye, aim, fov }` rides that thing in its frame: move or turn it, never re-pose each tick. `ctx.view.camera` takes both, never `place`. `place: "<id>"` films that place of this world while a player near the face sees it. A view draws only while a player sees its face, smaller and rarer on a weak device.
- The engine latches an arrival until they step clear: a player who turns straight around walks straight back. Arriving from ANOTHER world whose far gate does not link back opens a return rift behind the traveler for 30 s, shaped by `returnDoor` on the arrival place: `{ lifetime }` its seconds, `false` none; a door WITHIN your world opens none: its way back is a gate you build.
- Your held and worn things come through a door WITHIN your world. Into ANOTHER world, even one you edit, its `admits()` decides, at page loads too: the arrival place's `policy.admits`, else the world root's, else only its `world.config.yaml` `visitorsCarry: true` (default off). What you ride crosses on those terms or bounces whole at the glass. `admits()` reads how a thing comes in `ctx.crossing.actor.attachment`: `"attached"` (held or worn), `"ridden"` or `"loose"`. A refused thing is never lost: it waits in `player.pocket` (`ctx.self.pocket`, read-only `[{ objectId, kind, reason, from }]`, `[]` when empty), and returns to the hand in the next world admitting it (by default home admits its own, your den yours). With no body there, your carry script's drop with an empty hand and a full pocket answers the pocket (a notice your HUD draws from `reason`).
- Abroad the host's scripts turn your body and what it holds (a fresh world: toward the walk, not the look), so a held thing aiming with the eye aims from the look.
- Your `player.state` rides the door too. Where you arrive, that world's save of you wins for every key it holds; a carried key it lacks stands on you there, over the template's default, and enters its save only when a script there writes it.
- A travelling behavior runs abroad under the host's ceiling (its `world.config.yaml` `foreign: { faculties: [...] }`; unset = every word); one declaring nothing gets all but `write:world`. A top-level `export const faculties = ["write:self"]` narrows it to the words it names, of render, animate, audio, physics, collide, follow, attach, script, emit, spawn, write:self, write:world, voxel; reads, timers, `on` and queries are always free. A declared word the ceiling lacks pockets that behavior (the runtime log's `crossing.behavior.pocketed`); the thing keeps its others and re-binds it at home.
- `ctx.self.objectId`, `world:<birth>#<name>`, names a thing in every world; `id` is bare at home, the address abroad. A player and what spawns under one keep its session id `player/…` as both; `ctx.world.id` tells where. Key a ledger row on `objectId` (a player's on `userId`); `query({ objectId })` finds a thing after a hop.
